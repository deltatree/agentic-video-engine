# @agentic-video/mcp

MCP-Server: alle Agent-Operationen als MCP-Tools (stdio), dazu die Resources
`openvideo://agents.md` (Agent-Leitfaden), `openvideo://schema.json` (JSON Schema der IR) und
`openvideo://capabilities.json` (Capability-Manifest des Hosts).

```bash
openvideo mcp --project ./launch-video   # Projekt öffnen; project_open darf Ordner darin öffnen
```
