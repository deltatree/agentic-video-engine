# ADR 0016: Paketname @agentic-video, CLI openvideo

- Status: angenommen
- Datum: 2026-09-28

## Kontext

`openvideo` und `@openvideo/*` sind auf npm vergeben (2026-09-28).

## Entscheidung

Pakete heißen `@agentic-video/*`, die CLI `openvideo`, der Produktname steht in `PRODUCT_NAME`.

## Folgen

Der Name bleibt an einer Stelle austauschbar.
