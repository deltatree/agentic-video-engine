# ADR 0015: TypeScript 6.0 statt 7.0

- Status: angenommen
- Datum: 2026-09-28

## Kontext

TypeScript 7 (nativer Compiler) wird von typescript-eslint noch nicht unterstützt (npm, 2026-09-28).

## Entscheidung

Das Repo nutzt TypeScript 6.0.3.

## Folgen

Wechsel auf 7.x, sobald typescript-eslint es unterstützt.
